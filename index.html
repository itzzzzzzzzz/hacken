Hacken

/// Grundlagen

Was heißt Hacken?

Ein System dazu bringen, Dinge zu tun, die sein Erfinder nie vorgesehen hat.

  1. /// 01White HatHackt mit Erlaubnis, findet Lücken und meldet sie.
  2. /// 02Grey HatOhne Auftrag unterwegs, aber ohne böse Absicht.
  3. /// 03Black HatKriminell. Will Geld, Daten oder einfach Chaos.

/// Angriff

Phishing

Eine Nachricht, die echt aussieht. Sie will nur eins: dass du klickst, bevor du nachdenkst.

  1. /// 01Druck„Ihr Konto wird gesperrt.“ Eile ist der Trick.
  2. /// 02AbsenderEin vertauschter Buchstabe in der Adresse reicht schon.
  3. /// 03LinkErst prüfen, wohin er führt – dann klicken.

/// Ziel

Server

Auf Servern liegen die Daten von allen. Wer dort hineinkommt, erpresst, verkauft oder legt alles lahm.

  1. /// 01RansomwareVerschlüsselt alle Dateien und verlangt Lösegeld.
  2. /// 02DatenleckKundendaten landen im Netz und werden verkauft.
  3. /// 03DDoSEine Flut von Anfragen legt den Server lahm.

/// Abwehr

Schutz

Schutz ist kein Produkt, sondern eine Gewohnheit. An ihr scheitern die meisten Angriffe.

  1. /// 01Passwort-ManagerFür jedes Konto ein eigenes, langes Passwort.
  2. /// 02Zwei-FaktorEin zweiter Schlüssel: App oder Hardware-Key.
  3. /// 03UpdatesSchließen Lücken, die längst bekannt sind.
  4. /// 04Erst denkenDann klicken. Immer.
